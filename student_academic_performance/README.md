# Student Academic Performance Prediction using a Deep Neural Network

This project trains a three-class DNN using the UCI Student Performance dataset (Portuguese-language subject) and provides a Streamlit interface for predictions.

## Project structure

```text
student_academic_performance/
├── app.py
├── train_model.py
├── requirements.txt
├── README.md
└── artifacts/
    ├── model.keras
    ├── scaler.pkl
    ├── features.pkl
    └── metadata.json
```

The `artifacts/` files are generated by training. They are not included until you run the training script or copy them from Kaggle.

## Dataset

Use the Portuguese dataset file `student-por.csv` from the UCI Student Performance dataset:
https://archive.ics.uci.edu/dataset/320/student+performance

The CSV is semicolon-separated. Put `student-por.csv` in this project folder.

Dataset citation:
Cortez, P. (2008). Student Performance. UCI Machine Learning Repository. https://doi.org/10.24432/C5TG7T

## Run on Windows

1. Install Python 3.10 or 3.11.
2. Open this folder in VS Code.
3. Open the VS Code terminal and create a virtual environment:

   ```powershell
   py -3.11 -m venv .venv
   .venv\Scripts\activate
   ```

4. Install packages:

   ```powershell
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

5. Put `student-por.csv` in this folder and train:

   ```powershell
   python train_model.py
   ```

6. Start Streamlit:

   ```powershell
   streamlit run app.py
   ```

7. Open the local URL shown in the terminal (usually http://localhost:8501).

## Kaggle workflow

1. Create a new Kaggle Notebook.
2. Use **Add Input** to attach the UCI Student Performance dataset (or upload `student-por.csv` as a dataset).
3. Run the notebook cells for EDA and preprocessing as required by your assignment.
4. For training, upload `train_model.py` to the notebook or paste its contents into a cell. The script searches `/kaggle/input/**/student-por.csv` automatically.
5. Run:

   ```python
   !python train_model.py --output /kaggle/working/artifacts
   ```

6. Download `model.keras`, `scaler.pkl`, `features.pkl`, and `metadata.json` from `/kaggle/working/artifacts/`.
7. Copy these files into the local project's `artifacts/` folder. Keep the filenames unchanged.

If the Kaggle dataset uses a different filename or folder, find it with:

```python
import glob
glob.glob("/kaggle/input/**/*", recursive=True)[:50]
```

## Deploy on Streamlit Community Cloud

1. Test the app locally first.
2. Create a GitHub repository for this project.
3. Commit `app.py`, `requirements.txt`, `README.md`, and the complete `artifacts/` folder.
4. Open https://share.streamlit.io/ and sign in with GitHub.
5. Select **Create app**, choose your repository, branch, and `app.py`, then deploy.

Community Cloud installs the packages listed in `requirements.txt`. TensorFlow is a relatively large dependency, so the first deployment may take longer than a small Streamlit app.

## Target classes

- Low: G3 <= 9
- Medium: G3 from 10 through 14
- High: G3 >= 15

The input features are the same 14 features used in the training script. G1 and G2 are included, so predictions assume the first- and second-period grades are already known.

## Important modelling note

The dataset contains only 649 Portuguese-subject records. Report accuracy, precision, recall, F1-score and the confusion matrix; do not present accuracy alone. The model is a learning project and should not be used for high-stakes student decisions.
